# SMS Ledger v1.127

## Protection insurance covered-members and mobile UI fix
- Protection category and policy rows now use the same compact two-column design as My Ledger/Assets.
- Removed decorative insurance/warranty/maintenance icons from the category and policy rows.
- Insurance policy rows now show `Covered: <member names>` directly when covered members are recorded, or `Covered: Not specified` when missing.
- Insurance policy rows retain insurer/policy number on the left and sum assured on the right.
- Warranty and maintenance rows use the same two-column treatment.
- Insurance edit sheet retains the covered-member field and visible covered-member preview.
- Existing Family Hub and sharing behavior retained.
- Existing linked transaction behavior retained.
