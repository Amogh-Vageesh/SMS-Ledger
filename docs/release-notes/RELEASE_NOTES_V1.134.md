# SMS Ledger v1.134

## Changes
- Protection quick summary now keeps unlike values separate: total insurance cover, total insurance premium, total warranty cost, and total maintenance cost. Warranty cost no longer falls back to coverage/value in a cost summary.
- Protection category summaries now label insurance premiums and warranty/maintenance costs consistently.
- Subscriptions & Recurring remains a collapsible section when there are no entries, with an Add action and section-level sharing control available instead of disappearing into a plain card.

## Validation
- Source-level checks and ZIP integrity checks are run for this package. Android APK compilation/device verification is not claimed by this release note.
