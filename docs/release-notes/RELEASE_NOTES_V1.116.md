# SMS Ledger v1.116

## Protection item open/edit fix
- Insurance policies listed under their categories are now individually tappable.
- Warranties listed under their categories are now individually tappable.
- Maintenance plans listed under their categories are now individually tappable.
- Tapping an existing item opens its Edit sheet with the saved values.
- Existing Delete actions remain available from the edit sheet.
- Category summary rows remain non-editing headers, while individual policy/contract rows are the editable targets.
- Version: 1.116 / versionCode 111.
