# SMS Ledger v1.125

## Fixes and UI updates
- Fixed My Ledger rendering so the page content is populated instead of leaving the old summary/blank area.
- My Ledger uses collapsible Asset-style sections: Income, Expenses, Transfers, Expense Categories, Events, Subscriptions & Recurring, Recent Transactions.
- Removed the obsolete static period-summary strip from My Ledger.
- Added a Share button to My Ledger top-right.
- Added Family Hub at the top of Protection, matching the other financial pages.
- Added top-right Share control to Protection.
- Protection sharing now asks for selected family members and additional detail scopes before saving.
- Added detail scopes for Protection, Assets, Ledger and account sections to the section sharing flow.
- Protection shared data can omit financial values or covered-member details when those scopes are not selected.
- Asset shared data can omit financial valuation details and/or ownership details when those scopes are not selected.
- Preserved existing insurance/warranty/maintenance add/import/edit/delete and linked-transaction behavior.
