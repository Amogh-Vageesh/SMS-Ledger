# SMS Ledger v1.141

- Improved Family Hub header layout and spacing for narrow screens so Share and Manage family controls do not crowd the title or each other.
- Increased tap-target spacing between section Share controls and expand chevrons.
- Expanded linked-transaction lists use bounded, section-local scrolling.
- Subscription transaction-link picker period filters now anchor to the selected Ledger month/year rather than always using today's date.
- Tightened merchant-name fallback matching to reduce unrelated transactions appearing under a subscription.
- Kept the main Ledger period control to Month, Quarter, Yearly, and All years; added scoped CSS to suppress legacy transaction-type filters if present.
