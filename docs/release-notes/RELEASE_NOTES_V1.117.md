# SMS Ledger v1.117

## My Ledger period filters and subscriptions/recurring
- My Ledger period filter is now: Month, Quarter, Yearly, All years, Events.
- Added Quarter view with quarter navigation and income/expense totals.
- Moved Subscriptions & recurring out of the Assets page and into My Ledger.
- Added a collapsible Subscriptions & recurring section using the same compact Ledger/Assets visual language.
- Added subscription categories: Entertainment, Utility Bills, Insurance Premiums, Sports, Housing & Maintenance, Education, Telecom, Software & Apps, Memberships and Other.
- Added manual subscription/recurring setup with Monthly, Quarterly and Yearly frequency.
- Added Fixed vs Variable amount support.
- Variable recurring bills can optionally store unit, unit rate, minimum/base and maximum values.
- Linked Ledger transactions can be associated with a subscription/recurring item without creating duplicate financial entries.
- Subscription details show linked payment count and allow linking existing Ledger transactions.
- Recurring detection now supports variable-amount recurring bills instead of requiring the amount to remain within a fixed range.
- Detected recurring bills are grouped into useful subscription categories where possible.
- Dynamic bills such as electricity, water, gas and similar usage-based payments are displayed using their actual linked Ledger amounts for the selected period, with a Variable indicator.
- Added Subscriptions as a Ledger category option while preserving the separate subscription category used for subscription reporting.
- Existing loan, asset, Protection, SMS reconciliation and family functionality carried forward.
- Version: 1.117 / versionCode 112.
