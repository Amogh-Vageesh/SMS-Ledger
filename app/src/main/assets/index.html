Loan documents

Import loan documents separately from normal bank statements.

Use this for a payment/amortization schedule, a lender account statement, a top-up/sanction letter, or a balance-transfer/takeover document. The document updates the loan structure; it does not create fake cash transactions from a forecast schedule.

Select all yearly documents together. They will be processed as one batch against an existing asset and its linked loan; you will confirm the loan details only once.

Historical & missing-month import

Import window: January 2022 onward by default

SMS remains the primary source. Bank statements can fill missing periods from 2022, and you can optionally import transactions before 1 January 2022 for older history. Existing transactions are matched before anything new is added.
