# SMS Ledger v1.124

- My Ledger now uses Asset-style collapsible top-level sections: Income, Expenses, Transfers, Expense Categories, Events, Subscriptions & Recurring, Recent Transactions.
- Added Transfers section for internal transfers between owned accounts; these are excluded from income/expense totals.
- Added Events as a dedicated period-filtered section.
- Events is no longer a period-filter mode; Month/Quarter/Yearly/All years control all My Ledger sections.
- Preserved existing subscription, protection, asset and family-sharing logic.
