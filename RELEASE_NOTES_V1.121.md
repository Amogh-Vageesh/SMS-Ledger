# SMS Ledger v1.121

## UI restoration and mobile alignment
- Restored Protection to the established SMS Ledger insurance-row design used by the earlier sections instead of the newer nested card/grid treatment.
- Insurance, Warranty and Maintenance category headers and individual records use the same row geometry, typography, spacing and chevrons as the existing Ledger/Assets UI.
- Individual Protection records remain tappable and editable.
- Recurring/subscription category totals use one stable Ledger-style row per category; removed the two-column summary treatment that could overlap on narrow screens.
- Preserved the existing Assets compact row design and constrained name/value/chevron columns for narrow screens.
- No changes to underlying Protection, subscription, recurring, asset, loan or transaction data models.
